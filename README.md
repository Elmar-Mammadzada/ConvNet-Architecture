# ConvNet-Architecture
This assignment involves building and evaluating a Convolutional Neural Network (CNN) to perform multi-class image classification on the Intel Image Classification dataset (25,000 images, $150 \times 150$ resolution, across 6 landscape categories: buildings, forest, glacier, mountain, sea, and street). The technical objective is to construct an end-to-end computer vision pipeline—including normalization, data loading (configuring ImageFolder compatibility for unlabeled inference sets), loss and optimizer selection, model training with checkpoint saving based on minimum validation loss, and final evaluation on holdout test data.
